# ☕ Fern and Petal Cafe

A responsive, single-page cafe website built with plain HTML, CSS, and JavaScript to practice core front-end and DOM-manipulation skills. It presents a fictional garden cafe — menu, opening hours, an interactive order calculator, and a booking form — all running in the browser with no frameworks or build tools.

**Tech stack:** HTML5 · CSS3 (Flexbox, media queries, custom dark mode) · Vanilla JavaScript (no libraries)

---

## ✨ Features

- **Light / Dark mode toggle** — switch the whole page theme with one button.
- **Interactive order menu** — tick items to see a live running total, with row highlighting and category filters (All / Drinks / Pastries).
- **"Read More" toggle** in the About Us section.
- **Dynamic "Open / Closed" banner** based on the current time of day.
- **Booking form with validation** — personalized thank-you message plus an age-based discount check (student / senior).
- **Live character counter** on the special-requests field.
- **Fully responsive** layout for mobile and desktop.

## 🚀 How to Run the Project

You can view the live project directly here: **[Fern and Petal Cafe — Live Demo](https://khadeeja-taj.github.io/Coffee-Cafe/)**

> _If the live link is not working yet, GitHub Pages still needs to be enabled for this repository — see **[Enabling the live demo](#-enabling-the-live-demo-github-pages)** below._

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder and double-click the `index.html` file.
3. The assignment will open automatically in your default web browser.

*Note: For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.*

---

## 🌐 Enabling the Live Demo (GitHub Pages)

To publish this site for free with GitHub Pages:

1. Go to the repository on GitHub and open **Settings**.
2. In the left sidebar, click **Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select the **`main`** branch and the **`/ (root)`** folder, then click **Save**.
5. Wait a minute, then refresh. Your site will be live at:
   `https://khadeeja-taj.github.io/Coffee-Cafe/`

📖 Full step-by-step guide: <https://docs.github.com/en/pages/quickstart>
